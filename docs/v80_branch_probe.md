# v80 branch-conditioned probes
Experimental only. On the same 60 public v76 cases, v79 and v80 both reached 24 goals, with no paired changes, zero audited pose errors and four recorded mapping errors each. Actions increased from 1924 to 2003; unresolved localization increased from 33 to 35, while unspecified termination decreased from three to one. Reject promotion. Branch-specific static predictions inform action contrast; cap of 4096 distinct branches is checked before insertion, not a complete byte-memory bound. Pairwise contrast is a heuristic, not expected posterior entropy. No independent or fresh holdout. Five focused tests passed; 60 records replayed byte-identically. No acceptance status changes. Full suite not repeated; historical integration commit and official dependencies remain outstanding.

Reproduce: `OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 python -m experiments.branch_probe_study /tmp/v80.json verification/section08/v76/development.json verification/section08/v76/fresh.json` and compare with `verification/v80/trials.json`. Tests: `python -m pytest -o addopts='' -q tests/test_branch_probe.py tests/test_hypothesis_memory.py`.
