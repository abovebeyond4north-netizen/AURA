# Experimental protocol

`python -m experiments.baselines --config configs/cpu_smoke.yaml --seeds 2` produces five explicitly named conditions and separate development evaluation. This smoke comparison does not establish a statistical effect. For publication use multiple independent seeds, task-distribution-balanced splits, matching samples and compute, and externally embargoed final evaluation. Baseline A random does not train a model. Baselines B/C/D and candidate E train a model with different action selection/curriculum. In the current implementation candidate E's modification search is a **separate** controlled evaluation command, not automatically invoked during the main training loop. Thus E is not yet a complete end-to-end recursively improving competitor.

`python scripts/test_recursive_learning.py --steps 30 --replicates 5` records candidate lineage, matched budgets and a promotion decision. It only runs second-generation search if first-generation passes. Neither stage is scripted to pass. Test environments include key, switch, hidden randomized rule, altered movement and uncontrollable image noise. Record pre-registered metrics, uncertainty, retained performance and resource usage before interpreting generalization.
